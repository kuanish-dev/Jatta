# Формат курса Jatta

Курс — папка с `course.json` и темами в `topics/<id>.json`. Встроенный курс лежит в `content/en/`. Свою тему можно подключить в приложении: «Свои темы → Загрузить файл» на главной (один JSON-файл темы в том же формате). Загрузчик проверяет файл и отказывается грузить битый; проверить тему до загрузки можно скриптом:

```bash
python3 -I scripts/check_topic.py content/en/topics/money-words.json
```

## course.json

```json
{ "language": "en", "title": "Английский: от B1 к B2", "topics": ["work-words", "past-simple", "freq-1001"] }
```

`topics` — id тем в порядке курса. Новое берётся подряд в этом порядке; тема открывается, когда темы из её `requires` держатся в памяти (≥ 85% единиц вспомнятся завтра с вероятностью ≥ 85%).

## Тема

```json
{
  "id": "money-words",
  "title": "Слова: деньги",
  "intro": "Доходы и расходы, счета, долги и покупки.",
  "requires": [],
  "confusableWith": [],
  "items": [ … ]
}
```

| Поле | Что это |
|---|---|
| `id` | латиница, цифры и дефис; совпадает с именем файла и уникален в курсе |
| `title` | название на русском: «Слова: …», «Фразы на слух: …», для грамматики — само явление («Past Simple») |
| `intro` | 1–3 предложения: о чём тема; для грамматики — правило в двух словах. Показывается перед первой единицей темы |
| `requires` | темы, которые должны держаться в памяти, чтобы эта открылась; все они стоят в курсе раньше |
| `confusableWith` | темы, с которыми эту путают (Past Simple и Present Perfect); их повторы в занятии не перемешиваются |
| `items` | единицы: слова, сочетания или правила |

В теме слов и сочетаний — не меньше 4 единиц (иначе не из чего собрать варианты). Обычно 12–31, и лучше смешивать части речи вокруг одной ситуации, чем давать 25 прилагательных подряд: однотипные списки путаются при запоминании.

## Единица

```json
{
  "id": "w-account",
  "kind": "word",
  "en": "account",
  "ru": "счёт (в банке)",
  "rank": 436,
  "note": "Bank account — банковский счёт. Account — ещё и учётная запись в приложении.",
  "examples": [
    { "en": "I opened a new bank account last week.", "ru": "На прошлой неделе я открыл новый банковский счёт.", "gap": "account" },
    { "en": "The money is already in your account.", "ru": "Деньги уже на вашем счёте.", "gap": "account" }
  ]
}
```

| Поле | Слово (`word`) и сочетание (`phrase`) | Правило (`rule`) |
|---|---|---|
| `id` | `w-<слово>`; сочетания — `c-<слова-через-дефис>` | короткий префикс темы + суть: `ps-regular`, `pp-since-for` |
| `en` | слово или сочетание в словарной форме | образец формы: `worked, finished`, `If + had V3, would have V3` |
| `ru` | перевод, 1–3 значения через запятую; уточнение в скобках | правило одной строкой: что и когда |
| `also` | другие принимаемые ответы на ступени «Перевод»: `["flat"]` для `apartment` | не нужно |
| `rank` | ранг слова в NGSL 1.2 (`sources/ngsl/NGSL_12_stats.csv`), если слово там есть; иначе поля нет. У сочетаний нет | нет |
| `note` | объяснение: оттенки, типичные сочетания, чем отличается от похожих | объяснение правила и ловушки |
| `examples` | 2–3 примера, в каждом `gap` — слово в той форме, в какой оно стоит в примере | 3 примера с `gap`, `cue`, `wrong` |
| `audio` | только у записанных фраз Tatoeba: `file`, `by`, `license`, `source` | нет |

Пример (`examples[]`):

| Поле | Что это |
|---|---|
| `en` | английское предложение, 5–12 слов, естественное, про жизнь взрослого |
| `ru` | русский перевод, живой, не дословный |
| `gap` | слово или сочетание, которое прячется в пропуск; стоит в `en` целым словом в той же форме |
| `cue` | у правил: начальная форма для пропуска (`work` для `worked`), чтобы ученик знал, что вставлять |
| `wrong` | у правил: 2–3 неверных варианта для выбора (`work`, `works`, `working`); ни один не равен `gap` |
| `also` | другие верные переводы всего предложения на ступени «Перевод» (другой порядок слов) |

Как строятся упражнения по единице: узнавание (выбор из 4 переводов; у правил — выбор из `gap` и `wrong`), пропуск (`gap`), перевод (`en` по `ru`; у правил — перевод примера, свободный ответ проверяет модель), своя фраза (свободный ответ), вслух (сказать пример). Поэтому у каждого слова нужен хотя бы один пример с `gap`, у каждого правила — пример с `gap` и двумя `wrong`.

Что не берём: тексты из фильмов, книг под авторским правом и чужих учебников; слова о войне и политике; у слов вне NGSL `rank` не ставится.
