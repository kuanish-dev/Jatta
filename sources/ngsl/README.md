- `NGSL_12_lemmatized_for_teaching.csv` — headwords with their word forms.

Used only to check `rank` of words in `content/` (mechanic М8) and by `scripts/collect_texts.py`
to judge which reading texts a B1 learner can read (М11). Not shipped in the app.
